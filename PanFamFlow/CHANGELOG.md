# Changelog

## 0.1.0 - 2026-08-08

- Initial public alpha implementation.
- Added one-file YAML configuration validated with Pydantic.
- Added Python CLI for initialization, validation, planning, selective module execution and schema export.
- Added Snakemake 9 workflow with rule-specific Conda environments.
- Added modules for input audit, canonical transcript generation, family discovery, phylogeny, gene structure, OrthoFinder/HOG pangenome classification, chromosome summaries, duplication, Ka/Ks, promoter/FIMO, RNA-seq and HTML reporting.
- Added toy input, unit tests, CI and local/SLURM profiles.
