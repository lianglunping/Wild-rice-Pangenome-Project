# Hosting

The current feature branch is the auditable development location. Because the host repository contains unrelated whole-project pangenome code, the preferred public release target after the real-data benchmark is a standalone `lianglunping/PanFamFlow` repository containing only the software source, tests, examples, documentation, profiles and CI.

Until that migration, users should enter through `PanFamFlow/` rather than treating the host repository's original genome-assembly and pangenome-project directories as part of this workflow.
